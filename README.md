\# Da Vinci Code (C++ Number Guessing Game)



My first C++ practice project, started on 01/27/2026 while I was learning the language.



A console game: the program picks a secret number from 1 to 100, and you try to guess it.



\## Versions



Pick a version from the menu to play it.



\- v1: Core game loop and range check (1-100)

\- v2: Input validation (non-numbers), random feedback phrases, and a different message depending on how many tries you needed

\- v3: "Near-miss" hints when you are within 5, and no back-to-back repeated phrases
